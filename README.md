About
-----

This project is a fork of [pesXdecrypter](https://github.com/the4chancup/pesXdecrypter) and also implemented the decrypt/encrypt code from [libpes15crypter](https://github.com/the4chancup/libpes15crypter)

This fork has been migrated to Visual Studio (2022) solutions and is developed for personal and educational purposes.

For more information about the working/background, check out the original projects.

Usage
-----

This project uses solutions to setup and build it. To change the build type (static or dynamic library):
- Go to the Project's properties (right-click the project in solution explorer or select Project > Properties from the menu bar)
- In Configuration Properties > General, change the 'Configuration Type' to your needs
- To Build, simply run the 'Build Solution' or 'Build pesXdecrypter' under Build menu
